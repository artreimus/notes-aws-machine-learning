# MLA-C01 Study Roadmap

## Recommended Order

1. Read [[exam-overview]].
2. Review Domain 1 and refresh data preparation notes.
3. Review Domain 2 with SageMaker AI and built-in algorithm notes.
4. Review Domain 3 deployment, orchestration, and CI/CD notes.
5. Review Domain 4 monitoring, cost, security, and governance notes.
6. Use lifecycle notes to avoid memorizing obsolete answers.

## High-Yield Review Blocks

- Data quality, PII/PHI, bias, class imbalance, feature engineering.
- SageMaker AI training, tuning, built-in algorithms, deployment modes, monitoring.
- Bedrock prompt, RAG, guardrail, evaluation, and model routing patterns.
- CloudWatch, X-Ray, AWS Config, IAM, KMS, VPC endpoints, cost controls.
